# Cliply x Zenith 🚀🎨

**Cliply** is a high-performance, web-based screen recorder rebranded with the high-energy, cyberpunk **Zenith** aesthetic. Capture, annotate, and share your screen instantly with a professional, system-grade interface.

![Zenith Rebrand](https://images.unsplash.com/photo-1550745165-9bc0b252726f?q=80&w=2070&auto=format&fit=crop)

## ✨ Features

- **Neural Capture**: High-fidelity screen recording directly from your browser.
- **Neural Optical Overlay**: Persistent webcam overlay that stays in frame even when you switch windows.
- **Micro-Array & Neural Stream**: Capture crystal-clear microphone audio and system sound simultaneously.
- **Real-time Annotations**: Draw, highlight, and annotate your stream live during the recording phase.
- **Secure Uplink**: Password-protected sharing with automatic data cleanup.
- **Aesthetic Core**: Powered by the Zenith "Module 2" design system, featuring Teko typography and neon-green accents.

## 🛠️ Technology Stack

- **Frontend**: React, GSAP, Framer Motion, Lucide Icons.
- **Backend**: Python (Flask).
- **Styling**: Vanilla CSS with Zenith design tokens.
- **Engine**: Custom Canvas Compositor for real-time stream processing.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone <repository-url>
cd Cliply
```

### 2. Launch Backend
```bash
# It is recommended to use a virtual environment
cd backend
python3 app.py
```

### 3. Launch Frontend
```bash
cd frontend
npm install
npm run dev
```

## 🛰️ Module Configuration

- **MODULE_CONFIG**: Toggle Microphone, System Audio, and the Neural Optical (Webcam) overlay.
- **LIVE_RECORDING_STREAM**: Monitor your uptime and active waveform.
- **STREAM_UPLINK**: Generate secure share links with generated decryption keys.
